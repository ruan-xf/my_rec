## 分析方法说明

### cumulative_mae趋势与区间mae的关系

cumulative_mae(l) = E[error | L ≤ l] 的趋势变化反映了新增样本的性能：  

| 趋势 | 条件 | 含义 |
|-----|------|------|
| 下降 | 区间mae < 当前cumulative_mae | 新增样本性能更好，拉低累积误差 |
| 上升 | 区间mae > 当前cumulative_mae | 新增样本性能更差，拉高累积误差 |

**示例**（CNN模型）：  
- 区间{74.0,135.0}的mae=0.386 < cumulative_mae(74)=0.388 → 拉低至最低点
- 区间{279.0,792.0}的mae=0.431 > cumulative_mae(279)=0.387 → 拉高累积误差
