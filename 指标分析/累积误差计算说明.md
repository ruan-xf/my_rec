# 累积误差计算方法说明

## 问题背景

在序列长度性能分析中，需要计算特定长度区间内的平均误差。原有的实现存在累积值使用错误的问题。  

## 核心概念

### 1. 点值 vs 累积值

**点值（Point Values）- 在特定长度 l 上：**  
- `count(l)` = 样本数：长度恰好为 l 的样本数量
- `P(L = l)` = 概率：长度恰好为 l 的样本占比
- `M(l)` = E[error | L = l]：长度恰好为 l 的样本平均误差

**累积值（Cumulative Values）- 在长度阈值 l 上：**  
- `C(l)` = count(L ≤ l)：长度 ≤ l 的累积样本数
- `P(L ≤ l)`：长度 ≤ l 的累积概率
- `S(l)` = Σ|error| for L ≤ l：长度 ≤ l 的累积总误差
- `Φ(l)` = E[error | L ≤ l] = S(l) / C(l)：累积平均误差

### 2. 累积值的连续性

**关键特性：** 累积值在任何长度阈值上都有定义，不仅仅在实际出现的长度上。  

**示例：** 假设数据只有长度 [10, 20, 30]，我们要计算区间 (15, 25] 的积分：  
- C(15) = C(10)（累积到15等于累积到最大≤15的长度）
- C(25) = C(20)（累积到25等于累积到最大≤25的长度）

这确保了我们可以在任意区间上计算性能。  

## 公式推导

### 原公式（使用条件期望）

```
E[error | l_min < L ≤ l_max] = [Φ(l_max) × P(L ≤ l_max) - Φ(l_min) × P(L ≤ l_min)] / P(interval)
```

区间平均误差 = 区间内的总误差 /  N(interval) 与 区间内平均误差 = [Φ(l_max) × P(l_max) - Φ(l_min) × P(l_min)] / P(interval) 的等价性  


**公式1（样本数形式）**：  
```
区间平均误差 = 区间内的总误差 / N(interval)
```

**公式2（概率形式）**：  
```
区间平均误差 = [Φ(l_max) × P(l_max) - Φ(l_min) × P(l_min)] / P(interval)
```

证明过程  

**关键关系**  

样本数与概率的关系：  

```python
P(l) = N(l) / N_total      # N_total = 总样本数
P(interval) = N(interval) / N_total

反推：
N(l) = P(l) × N_total
N(interval) = P(interval) × N_total
```


**从公式1到公式2**  

**步骤1**：展开"区间内的总误差"  

```
区间内的总误差 = Φ(l_max) × N(l_max) - Φ(l_min) × N(l_min)
```

代入公式1：  

```
区间平均误差 = [Φ(l_max) × N(l_max) - Φ(l_min) × N(l_min)] / N(interval)
```

---

**步骤2**：将样本数转换为概率

```
N(l_max) = P(l_max) × N_total
N(l_min) = P(l_min) × N_total
N(interval) = P(interval) × N_total
```

代入：

```
区间平均误差 = [Φ(l_max) × P(l_max) × N_total - Φ(l_min) × P(l_min) × N_total] / [P(interval) × N_total]
```

---

**步骤3**：提取公因子 N_total  

```
区间平均误差 = N_total × [Φ(l_max) × P(l_max) - Φ(l_min) × P(l_min)] / [N_total × P(interval)]
```

---

**步骤4**：约去 N_total

```
区间平均误差 = [Φ(l_max) × P(l_max) - Φ(l_min) × P(l_min)] / P(interval)
```

✓ **得到公式2**

其中：
- Φ(l) = E[error | L ≤ l] = S(l) / C(l)
- P(interval) = P(L ≤ l_max) - P(L ≤ l_min)

### 新公式（使用累积总误差）

通过数学推导：

```
[Φ(l_max) × P(L ≤ l_max) - Φ(l_min) × P(L ≤ l_min)] / P(interval)
= [S(l_max)/C(l_max) × C(l_max)/N - S(l_min)/C(l_min) × C(l_min)/N] / P(interval)
= [S(l_max)/N - S(l_min)/N] / P(interval)
= [S(l_max) - S(l_min)] / (N × P(interval))
= [S(l_max) - S(l_min)] / C(interval)
```

**最终公式：**

```
E[error | l_min < L ≤ l_max] = [S(l_max) - S(l_min)] / C(interval)
```

其中：
- S(l) = 累积总误差
- C(interval) = count(l_min < L ≤ l_max)

### 新公式优势

1. **更简洁**：直接用累积总误差相减
2. **更直观**：总误差差值 ÷ 样本数
3. **避免混淆**：不需要概率和期望的乘积运算
4. **易于实现**：减少中间变量，降低出错风险

## 代码实现

### 1. 计算累积值（analyze_model 函数）

```python
# 初始化累积变量
cumulative_count = 0
cumulative_prob = 0.0
cumulative_mae_sum = 0.0  # 累积总绝对误差
cumulative_mse_sum = 0.0  # 累积总平方误差

for l in unique_lens:
    # 该长度的点值
    count = (seqlens == l).sum()
    prob = count / len(seqlens)
    mae_l = compute_performance_at_length(seqlens, abs_errors, l)
    mse_l = compute_performance_at_length(seqlens, squared_errors, l)

    # 累积值
    cumulative_count += count
    cumulative_prob += prob
    cumulative_mae_sum += mae_l * count  # 该长度的总绝对误差
    cumulative_mse_sum += mse_l * count  # 该长度的总平方误差
```

**关键点：**
- `mae_l * count`：该长度所有样本的绝对误差之和
- 累积总误差通过累加每个长度的总误差得到

### 2. 区间积分计算（compute_interval_integral_from_cumulative 函数）

```python
def compute_interval_integral_from_cumulative(df_analysis, interval):
    """
    利用累积总误差计算区间积分

    公式：E[error | l_min < L ≤ l_max] = [S(l_max) - S(l_min)] / C(interval)
    """
    l_min, l_max = interval

    # 找到 <= l_max 的最大长度（处理非连续长度）
    df_max = df_analysis[df_analysis['seq_len'] <= l_max]
    row_max = df_max.iloc[-1]

    # 找到 <= l_min 的最大长度
    df_min = df_analysis[df_analysis['seq_len'] <= l_min]
    if len(df_min) == 0:
        # l_min 小于最小长度，累积值从 0 开始
        cumulative_mae_sum_min = 0.0
        cumulative_mse_sum_min = 0.0
        cumulative_count_min = 0
        cumulative_prob_min = 0.0
    else:
        row_min = df_min.iloc[-1]
        cumulative_mae_sum_min = row_min['cumulative_mae_sum']
        cumulative_mse_sum_min = row_min['cumulative_mse_sum']
        cumulative_count_min = row_min['cumulative_count']
        cumulative_prob_min = row_min['cumulative_prob']

    # 区间内的总误差 = 累积到 l_max - 累积到 l_min
    interval_mae_sum = row_max['cumulative_mae_sum'] - cumulative_mae_sum_min
    interval_mse_sum = row_max['cumulative_mse_sum'] - cumulative_mse_sum_min

    # 区间内的样本数
    interval_count = row_max['cumulative_count'] - cumulative_count_min

    # 区间平均误差 = 区间总误差 / 区间样本数
    mae_interval = interval_mae_sum / interval_count
    mse_interval = interval_mse_sum / interval_count

    return {
        'mae': mae_interval,
        'mse': mse_interval,
        'count': interval_count,
        'prob': row_max['cumulative_prob'] - cumulative_prob_min
    }
```

**关键点：**
1. 使用 `df[df['seq_len'] <= l].iloc[-1]` 找到最接近的累积值
2. 区间总误差 = 累积到 l_max - 累积到 l_min
3. 避免了原实现中使用点概率 `row['prob']` 的错误

### 3. 处理边界情况

```python
if len(df_min) == 0:
    # l_min 小于最小长度，累积值从 0 开始
    cumulative_mae_sum_min = 0.0
    cumulative_mse_sum_min = 0.0
    cumulative_count_min = 0
    cumulative_prob_min = 0.0
```

当区间下界小于数据中的最小长度时，累积值从 0 开始。

## 验证方法

使用两种独立方法验证结果一致性：

### 方法1：分桶方法（直接计算）
```python
# 直接筛选区间内的样本计算
mask = (seqlens > l_min) & (seqlens <= l_max)
mae = np.abs(predictions[mask] - labels[mask]).mean()
```

### 方法2：积分方法（累积值计算）
```python
# 使用累积总误差的差值
mae = [S(l_max) - S(l_min)] / C(interval)
```

## 原有错误

### 错误代码
```python
# 错误：使用点概率代替累积概率
cum_prob_min = row_min['prob']  # 这是 P(L = l)，不是 P(L ≤ l)
cum_prob_max = row_max['prob']  # 这是 P(L = l)，不是 P(L ≤ l)

# 错误：使用点计数代替累积计数
interval_count = row_max['count'] - row_min['count']  # 这是 count(L = l)
```

### 正确代码
```python
# 正确：使用累积概率
cum_prob_min = row_min['cumulative_prob']  # P(L ≤ l_min)
cum_prob_max = row_max['cumulative_prob']  # P(L ≤ l_max)

# 正确：使用累积计数
interval_count = row_max['cumulative_count'] - row_min['cumulative_count']
```

## 总结

1. **累积值定义**：在任何长度阈值上都有意义，通过查找最大 ≤ l 的长度获得
2. **公式简化**：使用累积总误差使计算更直观，减少出错可能
3. **验证严格**：通过独立的分桶方法验证积分方法的正确性
4. **代码清晰**：新实现避免了概率和期望的混淆，逻辑更清晰

这种改进不仅修复了 bug，还使代码更易理解和维护。
