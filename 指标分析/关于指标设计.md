
## 概率分布视角的性能指标设计

### 核心思想
序列长度 L 是离散随机变量，我们关心：**模型误差随长度如何变化？**

概率分布理论提供了成熟的数学工具来描述随机变量。**关键洞察**：性能指标可以借鉴相同的数学结构：
- **CDF 的累积结构** → 累积性能函数 Φ(l)
- **PDF 的微分结构** → 性能密度 dΦ/dl
- **条件期望的框架** → 特定长度性能 M(l)

### 性能指标与概率概念的类比

#### 1. 形式类比：数学结构的相似性

| 概率论概念 | 性能指标 | 数学结构相似性 |
|-----------|---------|--------------|
| **条件期望** | **特定长度性能** | |
| E[X \| L=l] | M(l) = E[error \| L=l] | ★★★★★ 条件框架完全相同 |
| **CDF 累积结构** | **累积性能函数** | |
| F(l) = P(L ≤ l) = Σ p(l') | Φ(l) = E[error \| L≤l] | ★★★★☆ 累积运算相同，值不同 |
| **PDF 微分结构** | **性能密度** | |
| f(l) = dF/dl | dΦ/dl | ★★★★☆ 微分运算相同 |
| **CDF 差值计算** | **区间性能计算** | |
| P(a<L≤b) = F(b)-F(a) | E[error\|a<L≤b] = [S(b)-S(a)]/[C(b)-C(a)] | ★★★★★ 差值结构相同 |

**相似性评分说明**：
- ★★★★★：数学运算完全相同
- ★★★★☆：运算相同，但物理意义不同（概率 vs 误差）

**关键观察**：
- M(l) 继承了条件期望的完整框架
- Φ(l) 借鉴了 CDF 的累积结构：从"累积概率"到"累积误差期望"
- dΦ/dl 借鉴了 PDF 的微分思想：从"概率变化率"到"性能变化率"

#### 2. 作用类比：分析能力的相似性

**类比1：区间计算能力**

概率论中：
```
问题：区间 (a, b] 的概率是多少？
方法：P(a < L ≤ b) = F(b) - F(a)
优势：O(1) 查询，无需遍历数据
```

性能指标中：
```
问题：区间 (a, b] 的平均误差是多少？
方法：E[error | a < L ≤ b] = [S(b) - S(a)] / [C(b) - C(a)]
      其中 S(l) = cumulative_mae_sum, C(l) = cumulative_count
优势：O(1) 查询，无需遍历数据
```

**相似性**：两者都通过累积量之差实现高效区间计算

**代码验证**：`verify_interval_methods_consistency` 函数验证了积分方法与分桶方法的一致性

---

**类比2：趋势判断能力**

概率论中：
```
问题：概率在何处增长最快？
方法：观察 PDF（CDF 导数）
  - f(l) > 0：概率增长
  - f(l) 越大：概率增长越快
```

性能指标中：
```
问题：性能在何处改善最快？
方法：观察性能密度 dΦ/dl
  - dΦ/dl < 0：误差减小，性能**改善**
  - dΦ/dl > 0：误差增大，性能**恶化**
  - |dΦ/dl| 越大：性能变化越剧烈
```

**相似性**：两者都用导数判断变化方向和速率

**差异**：
- PDF 必须非负（概率非负）
- dΦ/dl 可正可负（误差可增可减）

**示例**：
- density_mae(l=50) = -0.0005：长度50附近，累积性能在改善（误差减小）
- density_mae(l=300) = +0.001：长度300附近，累积性能在恶化（误差增大）

---

**类比3：极值识别能力**

概率论中：
```
问题：哪个点的概率最大？
方法：找 p(l) 最大值 → 众数
```

性能指标中：
```
问题：哪个长度的性能最好/最差？
方法：
  - 直接找 M(l) 极值：性能最优/最差的长度
  - 找 dΦ/dl = 0 的点：性能转折点
```

**示例**：
- mae(l=135) = 0.302 最小：长度135的性能最好
- density_mae(l=200) = 0：长度200是性能转折点

### 与概率分布的关键差异

虽然性能指标借鉴了概率分布的数学结构，但两者有本质区别：

| 性质 | 概率分布 | 性能指标 | 原因 |
|-----|---------|---------|------|
| **归一性** | F(∞) = 1 | Φ(∞) = 全局平均误差 | Φ累积的是误差期望，不是概率 |
| **单调性** | F(l) 单调递增 | Φ(l) 不一定单调 | 误差可以改善或恶化，概率只能增大 |
| **非负性** | f(l) ≥ 0 | dΦ/dl 可正可负 | 误差可以减小（性能改善），概率只能增大 |
| **值域** | F(l) ∈ [0, 1] | Φ(l) ∈ [0, max_error] | 概率 vs 误差，量纲不同 |

**核心区别**：
- **概率描述"样本占比"**：样本分布是客观存在的，累积只能增加
- **性能描述"误差期望"**：模型性能可以改善或恶化，累积趋势不固定

这就是为什么 dΦ/dl 可以是负数（性能改善），而 PDF 必须非负。

### 完整示例（albert模型）

假设分析albert模型在序列长度 [1, 792] 上的表现：

**1. 性能层面**
- mae(l=50) = 0.308：长度恰好为50的样本平均MAE
- cumulative_mae(l=74) = 0.307：长度≤74的样本平均MAE
- 区间性能：
  ```
  E[error | 74 < L ≤ 135]
  = [S(135) - S(74)] / [C(135) - C(74)]
  = 0.302
  ```
  （S = cumulative_mae_sum, C = cumulative_count）

**2. 趋势判断**
- density_mae(l=50) = -0.0005 < 0：长度50附近，性能在改善
- density_mae(l=300) = +0.001 > 0：长度300附近，性能在恶化

**3. 极值识别**
- mae(l=135) = 0.302 最小：长度135性能最优
- density_mae(l=200) ≈ 0：长度200是性能转折点

**结论**：通过借鉴概率分布的数学结构，性能指标继承了相同的分析能力（区间计算、趋势判断、极值识别），差异仅在于物理意义（概率 vs 误差）。
